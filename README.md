# Twitter Clone



Twitter Clone to aplikacja webowa inspirowana serwisem X/Twitter, zbudowana w oparciu o Next.js, React i Firebase. Projekt odtwarza glowny uklad znany z platform spolecznosciowych: lewy panel nawigacji, centralny feed z postami oraz prawa kolumne z widgetami, trendami i sugestiami obserwowania.

Glowne zalozenie projektu to polaczenie nowoczesnego shellu aplikacji w Next.js z istniejacym interfejsem klienckim React. Autoryzacja zostala oparta o Clerk, a dane postow sa przechowywane i pobierane na zywo z Cloud Firestore.

## Najwazniejsze funkcje

- logowanie i zarzadzanie sesja przez Clerk
- publikowanie postow z tekstem i opcjonalnym obrazem przez URL
- pobieranie feedu w czasie rzeczywistym z Firestore
- widok Home z formularzem publikacji i lista postow
- dodatkowe sekcje, m.in. Explore, Notifications, Messages, Bookmarks, Lists i Profile
- prawa kolumna z trendami, wyszukiwarka i sekcja "Who to follow"
- interaktywny widok profilu z lokalna edycja avatara i bannera
- interfejs stylizowany na X/Twitter z wykorzystaniem Material UI i Tailwind CSS


## Stack technologiczny

- Next.js
- React 18
- React Router DOM
- Clerk
- Firebase / Cloud Firestore
- Tailwind CSS
- Material UI
- Styled Components / Emotion
